# Resume Insight Pro

Create a complete responsive web application called “AI Resume Analyzer” as a BCA 3rd-year mini project.

Objective

Build a simple and professional website that allows users to upload their resume, analyze it, generate a resume score, identify skills and skill gaps, compare the resume with a job description, and provide improvement suggestions.

Technology

Frontend: HTML, CSS, JavaScript

Backend: Python Flask

Database: SQLite

Resume formats: PDF and DOCX

Use free/open-source libraries where possible.

Main Features

Modern landing page with project name, description, and “Analyze Resume” button.

Resume upload supporting PDF/DOCX.

Extract text from the uploaded resume.

Analyze skills, education, experience, projects, certifications, and contact information.

Generate an overall resume score out of 100.

Display detected skills and missing/required skills.

Provide a Job Description input box.

Compare resume content with the job description and show a match percentage.

Provide personalized improvement suggestions.

Display results using clean cards, progress bars, and charts.

Allow users to download or print the analysis report.

Include an About Project section explaining the mini project.

UI Design

Use a professional dark-themed interface with a clean modern layout. Use attractive typography, responsive design, smooth animations, clear buttons, cards, icons, and a dashboard-style results page. Make it suitable for demonstrating on a college projector.

Important

Do not add user login or registration because this is a college mini project. Keep the application simple, functional, easy to demonstrate, and understandable for a BCA student.

Create the complete project structure, all frontend files, Flask backend, SQLite integration, required dependencies, setup instructions, and sample data. Ensure all frontend and backend components are properly connected and the project can run locally.
